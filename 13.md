# CORS
**CORS = Cross-Origin Resource Sharing**

And **CORS is primarily a browser security mechanism**—it isn't the firewall and doesn't control whether the server can technically receive a request.

Suppose your frontend is: https://frontend.com
and your backend is: https://api.backend.com

These are different **origins**.

The browser therefore applies CORS rules.

# 11. Simple CORS Request
Some cross-origin requests can be sent directly without first sending a preflight request.

These are called **simple requests** when they satisfy the CORS conditions.

For example, a basic:
GET /users

may be sent directly:
Browser
   │
   │ GET /users
   ↓
Backend
   │
   │ Access-Control-Allow-Origin: ...
   ↓
Browser

The browser checks whether the response has the appropriate CORS headers.

# 12. Preflight Request

A **preflight request** is a request the browser sends **before the actual request** to ask the server:

> "Are you okay with me sending this cross-origin request?"

The preflight uses: OPTIONS
Example:
Browser
   │
   │ OPTIONS /users
   ↓
Backend
   │
   │ "Yes, this origin/method/header is allowed"
   ↓
Browser
   │
   │ Actual request
   ↓
Backend

> Example

Suppose JavaScript wants to send:
DELETE /users/123
Authorization: Bearer xyz

The browser may first send:

OPTIONS /users/123
Origin: https://frontend.com
Access-Control-Request-Method: DELETE
Access-Control-Request-Headers: Authorization

The server might respond:
Access-Control-Allow-Origin: https://frontend.com
Access-Control-Allow-Methods: DELETE
Access-Control-Allow-Headers: Authorization

Then the browser sends:

DELETE /users/123

# 13. Simple Request vs Preflight

| Simple request                        | Preflighted request                           |
| ------------------------------------- | --------------------------------------------- |
| No preflight                          | Browser sends `OPTIONS` first                 |
| Actual request is sent directly       | `OPTIONS` checks permission first             |
| Must satisfy CORS "simple" conditions | Used when request needs additional permission |
| Example: basic `GET`                  | Example: `DELETE` with `Authorization`        |

Simple:

Browser ─────── GET ───────→ Server
        ←────── Response ───


Preflight:

Browser ───── OPTIONS ─────→ Server
        ←──── Permission ────
        │
        └──── Actual request ─→ Server
        ←──── Response ───────
